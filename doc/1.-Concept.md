### "Today many companies adopt the LAWICEL CAN ASCII protocol in their products."

> https://www.canusb.com/about/ (Accessed Jan. 12, 2026)

Although this firmware is not developed by a company,
it serves as one of such products that offers a casual way to connect to a single CAN FD network as a general‑purpose USB‑to‑CAN interface.


## Core values

1. Conpatibility with the LAWICEL CAN ASCII protocol
2. Simplicity - a human‑readable, text‑based protocol, less host coding
3. Reliability
4. Performance
