# General mechanism

The acceptance filter compares each received frame against a Code set by the `M` command and a Mask set by the `m` command. The filter mode is selected by the `W` command, and the 4-byte Code and Mask are interpreted differently depending on the selected mode.


# Dual filter mode (W0)

This mode is not yet implemented.
The filter always passes all frames in this mode for now.


# Single filter mode (W1)

This mode is not supported by this firmware.


# Simple filter mode (W2)

### Mechanism

The received frames are filtered based solely on their identifier extension bit (IDE) and CAN ID.
For filtering, the inversed IDE value (~IDE), combined with the CAN ID, 
is compared against the corresponding bits of the Code and Mask as shown below.

Mapping for a base CAN ID (11-bits)

| Item     | MSB      | ...        |     |            |                | LSB           | 
|----------|----------|------------|-----|------------|----------------|---------------|
| Code     | AC0 bit7 | AC0 bit6-0 | AC1 | AC2 bit7-3 | AC2 bit2-0     | AC3           |
| Mask     | AM0 bit7 | AM0 bit6-0 | AM1 | AM2 bit7-3 | AM2 bit2-0     | AM3           |
| Rx frame | 1 (~IDE) | -          | -   | -          | CAN ID bit10-8 | CAN ID bit7-0 |

Mapping for an extended CAN ID (29-bits)

| Item     | MSB      | ...        |                 |                 |                | LSB           | 
|----------|----------|------------|-----------------|-----------------|----------------|---------------| 
| Code     | AC0 bit7 | AC0 bit6-5 | AC0 bit4-0      | AC1             | AC2            | AC3           |
| Mask     | AM0 bit7 | AM0 bit6-5 | AM0 bit4-0      | AM1             | AM2            | AM3           |
| Rx frame | 0 (~IDE) | -          | CAN ID bit28-24 | CAN ID bit23-16 | CAN ID bit15-8 | CAN ID bit7-0 |

Here '-' indicates that the corresponding bit is not used for the acceptance decision.
A received frame is accepted if the following condition is satisfied for every bit:

` (Code) & (~Mask) == (Rx frame) & (~Mask) `

### Examples

Example 1:
* Mode - `W2[CR]`
* Code - `M00000000[CR]`
* Mask - `mFFFFFFFF[CR]`

All bits are disabled by acceptance mask i.e. all frames are received.
This is default when power on.


Example 2:
* Mode - `W2[CR]`
* Code - `M80000100[CR]`
* Mask - `m00000000[CR]`

The base CAN ID `0x100` is accepted and the other base CAN IDs are ignored.
All extended CAN IDs are ignored.


Example 3:
* Mode - `W2[CR]`
* Code - `M18DB0000[CR]`
* Mask - `m0000FFFF[CR]`

All extended CAN IDs between `0x18DB0000` and `0x18DBFFFF` are accepted.
The other extended CAN IDs and all base CAN IDs are ignored.


Example 4:
* Mode - `W2[CR]`
* Code - `M00000100[CR]`
* Mask - `m80000000[CR]`

The base CAN ID `0x100` and the extended CAN ID `0x00000100` are accepted and the other CAN IDs are ignored.
