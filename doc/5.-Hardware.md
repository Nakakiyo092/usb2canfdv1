# Hardware type

The USB2CANFDV1 has three LEDs.

| Label  | Color | Description                |
|--------|-------|----------------------------|
| RDY    | Red   | Power, Upgrade/Normal mode |
| RX     | Green | Data reception             |
| TX     | Blue  | Data transmission          |


# LED behavior
The rules are applied from top.
The LEDs do not depend on the `F` command. Reading the status flags does not change the LEDs.

### Upgrade mode

* RDY: Blink

### Startup

* RDY: Constant ON
* RX & TX: Blink in turn, 5 times in total

### Bus off

* RDY: Constant ON
* RX & TX: Blink together until the CAN FD channel is closed

### CAN error

* RDY: Constant ON
* RX & TX: Constant ON while the CAN node is error passive,
  and for a short time after any CAN protocol error

### Data loss

* RDY: Constant ON
* RX: Constant ON for a short time after any data is discarded
* TX: OFF for the same time

### CAN bus closed

* RDY: Constant ON
* RX: Blink by a command reception
* TX: Constant ON

### CAN bus open

* RDY: Constant ON
* RX: Blink by a CAN frame reception
* TX: Blink by a CAN frame transmission
